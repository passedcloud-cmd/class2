# PRD: TODO 앱 우선순위 태그

## 배경 / 문제
할 일이 많아질수록 어떤 일부터 처리해야 할지 헷갈리는 문제가 있다. 할 일마다 중요도를 표시할 방법이 없어서, 목록을 훑어봐도 우선순위 판단을 사용자가 매번 머릿속으로 해야 한다.

## 목표
- 할 일마다 우선순위(높음/보통/낮음)를 지정할 수 있게 한다.
- 우선순위 기준으로 목록을 정렬해서 무엇부터 해야 할지 한눈에 파악할 수 있게 한다.

목표가 아닌 것:
- 우선순위를 시스템이 자동으로 추천/판단해주는 것
- 화면 전체 디자인을 새로 바꾸는 것 (우선순위 태그 관련 요소만 추가)

## 유저 스토리
- 개인 사용자로서, 나는 각 할 일에 우선순위를 지정하고 싶다. 왜냐하면 할 일이 많아졌을 때 무엇부터 처리해야 할지 빠르게 판단하고 싶기 때문이다.

## 범위

### In scope
- 할 일 생성/수정 시 우선순위를 높음/보통/낮음 중 하나로 선택
- 우선순위를 선택하지 않으면 기본값으로 '보통' 적용
- 할 일 목록을 우선순위 순(높음 → 보통 → 낮음)으로 정렬해서 표시
- 같은 우선순위 안에서는 생성일 순(먼저 추가한 순)으로 정렬

### Out of scope
- 우선순위 자동 추천/자동 분류 기능
- 화면 전체 레이아웃/디자인 변경 (우선순위 태그를 위한 최소한의 UI 요소 추가만 포함)

## 성공 기준
- 할 일을 만들거나 수정할 때 우선순위(높음/보통/낮음)를 선택할 수 있다
- 우선순위를 선택하지 않으면 자동으로 '보통'이 적용된다
- 할 일 목록이 우선순위 순(높음 → 보통 → 낮음)으로 정렬되어 표시된다
- 같은 우선순위 내에서는 생성일 순으로 정렬된다

## 기술적 고려사항 / 제약
- 현재 TODO 앱 코드가 없는 상태의 기획 단계 문서로, 특정 기술 스택이나 기존 코드와의 연동 제약은 없다
- 실제 구현 시 사용할 스택/저장 방식은 이 PRD 범위 밖이며, 구현 착수 시점에 별도로 결정한다

## 미해결 질문
- 없음 (기획 연습 목적의 PRD이며, 실제 구현은 이번 범위에 포함하지 않음)
