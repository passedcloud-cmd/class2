#### 워드 임베딩과 RNN
원-핫 인코딩: 단어를 하나만 1이고 나머지는 0인 벡터로 표현. 유의어 표현 못함
워드 임베딩: 단어들 사이의 의미적 관계를 포착할 수 있는 밀집되고 연속적/분산적인 벡터로 나타내기. 공간상 가깝거나 멀게 위치 
Word2Vec: 구글이 개발한 워드 임베딩 방법. 각 단어와 주변 단어들 간의 관계를 예측. SG와 CBOW 2가지 방식 있음 
Skip-grams(SG) 방식: 중심 단어를 통해 주변 단어들을 예측
윈도우 크기: 중심 단어 주변 몇 개 단어를 문맥으로 볼 것인가?
적은 데이터, 희귀 단어에 강함. 학습 속도 느림 
Continuous Bag of words(CBOW) 방식: 주변 단어로 중심 단어 예측. 문맥.
학습 속도 빠름. 희귀 단어에 약함 

순차적 데이터: 순서 중요. 장기 의존성. 가변 길이 
선형회귀, MLP로 처리 불가능. 전통적인 인공신경망(MLP, CNN)은 고정 길이 입력을 받음 
RNN, LSTM, Transformer 등 sequential models 필요.

RNN(Recurrent Neural Network, 순환 신경망)
가변 길이 입력 받을 수 있음. 이전 입력 기억 가능. ono to one/many to one/one to many/ many to many
이전 시점의 정보를 담는 hidden state
입력 시퀀스 벡터 x를 처리할 때마다 recurrence 수식을 적용하여 hidden state를 업데이트. 동일한 가중치w를 사용. 한번에 하나의 요소 처리하고 앞으로 전달 
기울기 소실 문제: 역전파 시 앞쪽 층의 기울기가 0에 가까워짐 

LSTMs: short-term information을 저장하는 hidden state와 long-term information을 저장하는 cell state를 가짐.
cell state는 정보를 읽고, 지우고, 기록할 수 있음 
Forget gate: 이전 cell state에서 무엇을 버리고 기억할지 결정
Input gate: 새 정보 중 얼마를 cell state에 쓸지 결정
output gate: cell state 중 얼마를 hidden state로 보낼지 결정 
게이트는 동적으로 계산되고 각 요소는 열림(1), 닫힘(0), 그 사이의 값으로 설정됨 


#### 자연어 생성 모델 (Seq2Seq와 attention)
언어모델: 인간의 두뇌가 자연어를 생성하는 능력을 모방한 모델. 단어 시퀀스 전체에 확률을 부여하여 문장의 자연스러움을 측정 
한 문장의 확률: 각 단어의 조건부 확률들의 곱 
N-gram 언어모델: 연속된 n개의 단어 묶음. 직전 3개 단어만 고려 
코퍼스 = 말뭉치 
SMT(Statistical Machine Translation): 번역 모델(단어와 구가 어떻게 번역되어야 하는지 모델링. 한국어, 영어 코퍼스로 학습 )과 언어모델(유창한 영어 문장을 쓰는 방법을 모델링. 영어 데이터 학습)로 나누는 방법 - 베이즈 룰
SMT(Statistical Machine Translation)의 한계: 구조적 복잡, 수작업, 자원 구축, 유지 확장 어려움. 이런 한계로 기계 번역은 NMT(Neural Machine Translation)으로 넘어감.

NMT: 인공 신경망으로 기계 번역을 수행. 이때 사용하는 신경망 구조를 Seq2Seq라고 하며, 두 개의 RNNs(LSTM)으로 이루어짐 
번역은 입력과 출력 길이가 다름. 길이가 다른 시퀀스 간 매핑을 처리해야 함.

Seq2Seq: 2개의 LSTM 이용. 한 LSTM은 입력 시퀀스를 한 타임스텝씩 읽어서 고정된 차원의 큰 벡터 표현을 얻음(Encoder). 다른 LSTM은 앞에서 얻은 벡터로부터 출력 시퀀스를 생성함(Decoder) 
기계 번역, 요약, 대화, 코드 생성 등에 적용 가능 
Seq2Seq 모델은 인코더와 디코더가 하나의 통합 네트워크로 연결.
디코더에서 발생한 오차는 역전파 과정을 통해 입력을 처리한 인코더까지 전달, 전체 네트워크가 End-to-End로 동시에 최적화 
학습 초반에는 예측 능력이 떨어져 학습이 불안정함
Teacher Forcing: 정답 단어를 디코더 입력으로 강제로 넣어줌으로써 빠르고 안정적으로 학습을 수행 
토큰 출력 방법1 Greedy inference: 가장 확률이 높은 단어를 선택해 출력. 되돌리기 불가능 
토큰 출력 방법2 Beam search: 매 단계마다 k개의 유망한 후보 유지. 후보가 <EOS>에 도달하면 완성된 문장으로 리스트 추가. <EOS> 문장이 충분히 모이면 탐색 종료. 각 후보들의 점수를 로그 확률의 합으로 구해 최종 선택 
Seq2Seq의 한계: bottleneck problem
인코더는 입력 문장 전체를 하나의 벡터로 요약, 마지막 hidden state에 문장의 모든 의미 정보가 담김
고정 길이 벡터 하나에 모든 문장의 의미를 압축하다 보니 정보 손실이 생기는데, 이를 bottleneck problem이라고 함 

Attention: 디코더가 단어를 생성할 때, 인코더 전체 hidden state 중 필요한 부분을 직접 참조할 수 있도록 함. 매 타임스텝마다 어떤 단어/구절에 집중할 지 가중치로 계산하여 bottleneck 문제 완화. 
NMT 성능 향상: 디코더 문장 전체가 아닌 필요한 부분에만 집중
Bottleneck problme 해결: 디코더가 인코더의 모든 hidden states에 접근
vanishing gradient problem 완화: 멀리 떨어진 단어도 직접 연결 
BLEU score: 기계 번역의 출력이 사람 번역과 얼마나 비슷한지 평가하는 지표 
Attention의 효과1: 해석 가능성(Interpretability). Attention 분포를 보면 decoder가 어떤 단어를 생성할 때 입력 문장의 어느 부분에 집중했는지 확인 가능. 모델이 내부적으로 참고한 근거를 사람이 파악 가능. 의사결정 과정을 해석할 수 있음
Attention의 효과2: 정렬(Alignment). decoder가 필요한 입력 단어에 자동으로 집중하기 때문에 단어와 단어 간의 매핑 관계를 자연스럽게 학습. 기계번연은 단어 alignment 모델을 따로 학습해야 했는데 Attention에선 필요 없어짐.
Attention: Query와 values
Seq2Seq에서 attention을 사용할 때 각 decoder의 hidden state와 모든 encoder의 hidden states간의 관계를 Query와 Values의 관계로 볼 수 있다.
1. Query와 values 사이 유사도 점수(score) 계산
dot-product(내적. score = Q · K Query 벡터와 Key 벡터를 그냥 내적(같은 위치끼리 곱해서 다 더하기)
multiplication(중간에 학습 가능한 가중치 행렬 W를 하나 끼워 넣어요score = Q · W · K)
additive(작은 신경망(MLP) 하나를 새로 만들어서 점수를 계산score = v · tanh(W1·Q + W2·K))
2. softmax를 통해 확률 분포(attention distribution) 얻기
3. 분포를 이용해 values를 가중합 -> context vector(attention output)

RNN (기울기 소실 문제)
  ↓ 개선
LSTM (게이트로 완화)
  ↓ 2개 조합
Seq2Seq (인코더 LSTM + 디코더 LSTM)

Attention 알고리즘 (Seq2Seq에 추가됨)

#### 트랜스포머
RNN은 정보를 hidden state로 전달하여 순차적 의존성을 형성
RNN의 한계점1: 장기 의존성. RNN은 왼쪽에서 오른쪽으로 순차 전개. 단어 쌍이 상호작용하려면 시퀀스 길이만큼 단계를 거쳐야 함. 
길어진 단계만큼 기울기 소실 혹은 폭발 문제가 발생. 또한 입력된 선형 순서를 강하게 반영하여 언어의 비선형적 의존성을 잡아내지 못함. 
RNN의 한계점2: 병렬화. Forward와 Backward pass 모두 시퀀스 길이 만큼의 단계가 필요. 순차적인 연산이 진행되어 병렬화가 불가능. 병렬 연산에 강한 GPU 활용이 어려워 대규모 데이터 학습에 비효율적. 

Attention은 각 단어의 표현을 query로 두고, value 집합으로부터 필요한 정보를 직접 불러와 결합함. 이러한 attention 메커니즘을 encoder-decoder간이 아닌 한 문장 내부에서 적용하면 -> self-attention
Self-attention의 장점: 순차적으로 처리해야 하는 연산 수가 시퀀스 길이에 따라 증가하지 않음. 최대 상호작용 거리=O(1) -> 모든 단어가 각 층에서 직접 상호작용함. 
Attention에서 각 단어 i를 표현하는 Query와 Value 벡터가 있듯이, Self-Attention에서는 각 단어 i를 표현하는 Query, Key, Value 벡터가 있음
Query 벡터: 단어 i가 다른 단어로부터 어떤 정보를 찾을지 정의
Key 벡터: 단어 i가 자신이 가진 정보의 특성을 표현
Value 벡터: 실제로 참조되는 정보 내용을 담고 있는 벡터
1. 각 단어를 Query, Key, Value 벡터로 변환 
2. Query, Keys간의 유사도를 계산하여 softmax 확률분포를 구함
3. 각 단어의 출력을 values의 가중합으로 계산 
Key 벡터는 다른 단어의 Query와 비교되어 어텐션 스코어(유사도)를 계산하는 용도이고, Value 벡터는 그 스코어(가중치)로 가중합되어 실제 출력을 만드는 정보의 내용을 담음
Self-Attent의 한계
단어 간 관계를 효율적으로 잡아내지만 다만
1. 순서 정보 부재: 단어의 유사도만 계산. 순서 고려 안함
2. 비선형성 부족: Attention 계산은 가중 평균 연산이라는 선형 결합에 불과하여 복잡한 패턴이나 깊은 표현력은 담기 어려움.
3. 미래 참조 문제: 언어 모델은 시퀀스를 왼쪽에서 오른쪽으로 생성해야 하는데, Self-Attention은 모든 단어를 동시에 보기 때문에, 아직 생성되지 않아야 할 미래 단어를 참조함 
Self-Attention의 한계 해결1: Positional Encoding
각 단어 위치 i를 나타내느 위치 벡터를 정의하여 단어 임베딩 값에 더해 최종 입력으로 사용. 두 가지 방법 있음.
Sinusoidal Position Encoding: 서로 다른 주기의 사인/코사인 함수를 합성해 위치 벡터를 만드는 방법
Learned Absolute Position Embedding: 위치 벡터를 모두 학습 파라미터로 설정해 학습 과정에서 데이터에 맞춰 최적화 
Self-Attention의 한계 해결2: Feed-Forward NetWork 추가하기
각 단어 출력 벡터에 Feed-Forward Network(Fully Connected + ReLU 등)을 추가해 Self-Attention이 만든 표현을 깊고 비선형적인 표현으로 확장 
Self-Attention의 한계 해결3: Masked Self-Attention
Attention score를 계산할 때, 미래 단어에 해당하는 항목을 -무한으로 설정하여, 계산을 수행할 때 반영되지 않도록 한다. 
정리
Self-Attention은 문장 내 모든 단어가 서로 직접 상호작용하여, 1) 장거리 의존성을 효율적으로 포착하고 2) 병렬 처리를 가능하게 하는 메커니즘
한계 해결 방법:
1. 순서 정보 부재 -> Positional Encoding
2. 비선형성 부족 -> Feed-Forward Network 추가
3. 미래 참조 문제  -> Masked Self-attention

Transformer: Self-Attention을 핵심 메커니즘으로 하는 신경망 구조 
encoder-decoder 구조로 설계됨
단일 형태의 고정된 연결 패턴을 유지하는 것이 아니라, 어떤 레이어에서는 CNN(특정 주변 영역에 주목)처럼, 어떤 레이어에서는 RNN(순차 정보에 주목)처럼, 어떤 레이어에서는 MLP처럼(문장 전체 단어들에 균등하게) 필요한 최적의 아키텍처 연산 방식을 스스로(동적으로) 학습
encoder: 입력 문장을 받아 의미적 표현으로 변환을 수행
decoder: 인코더의 표현과 지금까지 생성한 단어들을 입력 받아, 다음 단어를 예측함 
Multi-Headed Attention
단일 self-Attention Head로는 한 가지 관점에서 단어 간 관계 밖에 파악할 수 없음
그래서 여러 Attention Head를 두어 다양한 관점에서 동시에 정보를 파악함. 단어의 문맥적 관계에 attention, 단어의 시제에 attention, 명사에 attention...
Scaled Dot product: Query와 Key의 차원이 커질수록 두 벡터의 내적 값도 자연스레 커짐. 값이 너무 크면 softmax 함수 출력이 지나치게 뾰족해져 미세한 변화에도 큰 차이가 발생하고 gradient vanishing 문제가 생길 수 있음. 그래서 내적 값을 그대로 사용하지 않고 나눠주어 스케일을 조정함. 그러면 값이 안정적으로 분포되어 학습이 훨씬 더 빠르고 안정적으로 진행됨 
Residual Connection: 깊은 신경망은 층이 깊어질수록 학습이 어려워짐 (기울기 소실/폭발). 그래서 기존 입력과의 차이만 학습하도록 하는 residual connection을 사용
위치 정보를 포함한 입력(x̂ᵢ = xᵢ + pᵢ)은 여러 블록을 통과할수록 희석되는 경향이 있는데, 잔차 연결이 매 레이어마다 원래 입력을 다시 더해줌으로써 이 위치 정보가 깊은 레이어까지 잘 유지되도록 해줘요.
Layer Normalizaion: 층이 깊어질수록 hidden vector값이 커졌다 작아졌다 하면서 학습이 불안정함. Layer Normalization은 각 레이어 단위에서 hidden vector 값을 정규화하여 안정적이고 빠른 학습을 도움 
Decoder: 트랜스포머의 디코더는 여러 개의 디코더 블록들을 쌓아 올려 만든 구조. 4개 구조로 구성
Masked self-attention(multi-head), Add&Norm(Residual Connection + Layer Normalizaion), Feed-Forward Network(비선형 변환), Add&Norm(Residual Connection + Layer Normalizaion)
언어 모델처럼 단방향 문맥만 활용
Encoder: 양방향 문맥 모두 활용 가능. 입력 문장을 의미적 표현으로 변환. 각 반 단어가 양방향 문맥을 모두 반영한 벡터로 인코딩됨. Decoder와의 차이점은 self-attention에서 masking을 제거한 것 뿐. 

Encoder-Decoder: 트랜스포머도 이해를 위한 encoder와 생성을 위한 decoder로 이뤄진 encoder-decoder 구조를 채택
decoder는 단순 self-Attention만 하는 것이 아니라 encoder의 출력 표현을 참조하는 cross-attention을 추가하여 입/출력을 연결
Cross-Attention: Self-attention과는 다르게 Query는 decoder에서, Key와 value는 encoder에서 가져옴 
트랜스포머의 등장은 최신 모델들이 사전학습(pretraining)을 결합하도록 함. 뛰어난 병렬 처리 능력 덕분에 대규모 사전학습에 적합하여 NLP의 표준 아키텍쳐로 자리 잡음 


#### 사전 학습 기반 언어 모델
사전학습: 대규모 데이터 셋을 이용해, 모델이 데이터의 일반적인 특징과 표현을 학습하도록 하는 과정. 일반적인 언어 패턴, 지식, 문맥 이해 능력을 습득 
워드 임베딩의 경우 사전학습을 통해 단어의 의미를 학습하는 데 한계 존재. 다운스트림 태스크(텍스트 분류)에 적용하기에는 학습되는 데이터의 양이 적음. 그리고 연결된 네트워크가 무작위 초기화되어 학습 효율이 낮음. 
언어 모델의 경우 모델 전체를 사전학습을 통해 학습하기 때문에 강력한 NLP 모델을 구축하는 데에 이점이 있음. 언어에 대한 표현 학습용으로 적합. 파라미터 초기화 관점에서 효과적. 언어에 대한 확률 분포 학습을 통해 샘플링, 생성에 사용 가능. 
언어 모델의 사전 학습: 과거 단어가 주어졌을 때 다음 단어의 확률 분포를 모델링하는 방법을 배워 사전학습을 수행. 인터넷의 대규모 텍스트 코퍼스에서 언어모델링 학습을 수행 후 학습된 네트워크 파라미터를 저장, 다양한 다운스트림 태스크에 활용
사전 학습 -> 파인 튜닝 패러다임: 사전학습으로 언어 패턴을 잘 학습한 파라미터로 초기화해 NLP application 성능을 향상 시킬 수 있음

양방향 문맥을 모두 활용
BERT: Masked LM방법으로 사전학습을 수행한 모델
학습 방법1: Masked LM.
입력 토큰 일부를 [MASK] 토큰으로 치환하여 모델이 해당 자리에 올 단어를 예측하도록 학습. 모델이 마스크된 단어에만 집중하지 않고 다양한 문맥 표현을 학습해 더 강건한 표현을 학습하도록 함 
학습 방법2: Next Sentence Prediction(NSP)
입력을 두 개의 연속된 텍스트로 받아, 두 번째 문장이 첫 번째 문장의 실제 다음 문장인지 여부를 예측. 문맥적 추론 및 문장 수준 이해.
Input이 들어오면 Token Embeddings, Segment Embeddings, Position Embeddings 을 합침 
[CLS]: 시작 토큰, [SEP]: 끝내는 토큰 
*세그먼트 임베딩(Segment Embedding)은 입력 텍스트에서 두 개의 문장을 구분하기 위해 BERT 같은 언어 모델에서 사용하는 기법입니다. 각 토큰이 첫 번째 문장에 속하는지, 두 번째 문장에 속하는지를 판별하는 역할을 합니다

BERT의 다운스트림 테스크: MLM과 NSP 두 가지 테스크를 동시에 학습. 
MLM : 마스크 자리에서 전체 단어 사전 크기만큼의 확률 분포를 출력하고 교차 엔트로피 손실을 계산한다
[CLS] 토큰은 NSP 태스크 용으로 학습, 다른 토큰들은 MLM 태스크 용으로 학습 
Sentence level 태스크(두 문장 관계 분류, 단일 문장 분류)
Token level 태스크(QA 태스크, 개체명 인식)
BERT는 레이어 수, hidden state의 크기, attention head의 수가 클수록 성능이 향상됨 
BERT의 한계: 인코더 기반 모델인 BERT는 주어진 입력은 잘 이해하지만 시퀀스를 생성해야 하는 태스크에는 적합하지 않음(기계 번역, 텍스트 생성 등). 한 번에 한 단어씩 생성해야 하는데, 이를 자연스럽게 수행하지 못하기 때문에 생성 태스크엔 디코더 기반 모델을 주로 사용

y= W · x

CNN모델
합성곱 레이어(convolution layer)
필터를 원본에서 이동시키면서 입력 값과 곱하고 합산하여 특징 맵(feature map)을 뽑아냄
이미지와 필터의 깊이/채널이 같아야 함 
필터 1개당 활성화맵 1개 
필터가 6개면 활성화 맵도 6개
출력 해상도 = 입력 해상도 - 필터 해상도 +1
입출력 해상도를 유지하고 싶다면 1. 제로패딩 2. 가까이에 있는 값 채워넣기
가중치 w와 bias가 합성곱 레이어의 상수

모델 상수(파라미터)를 증가시키려면 ReLU라는 조건부 스위치를 끼워야 함. 비선형 블록(Conv+ReLU)

필터 시각화
선형 모델: 객체의 특징 반영 못함
FCN: 색깔, 위치 등 다양한 템플렛이 나옴
CNN: 계층별로 다른 이미지

수용 영역: CNN이 이미지를 처리하면서 한 번에 볼 수 있는 영역의 크기
네트워크가 깊어질 수록(레이어를 많이 통과할수록) 수용영역도 넓어짐
수용영역 확장 방법: Deep stacking(conv layer를 깊게 쌓음), pooling, stride, dilated Conv 등
conv : 레이어를 깊게 쌓는 구간
pooling, stride, dilated(확장된) conv : 연산의 효율성을 위해 해상도를 줄이면서 깊이를 쌓음. 

pooling:  feature map의 크기를 줄이는(다운샘플링) 연산
해상도를 작게 만듦. 출력을 줄여서 연산량을 줄이기
위치 변화 강건성(환경 변화에도 유지) : 이미지 내 객체 위치가 변해도 동일 출력 제공
몇 화소 정도 이동돼도 괜찮음
맥스 풀링: 정해진 커널 사이즈(예: 2x2)로 이미지를 나누어 각 영역 내 가장 큰 값을 선택하는 연산. 모델 상수 없음. 나머지 정보를 그냥 버려서 손실이 큼. 

스트라이드 합성곱: 필터를 스트라이드 값 S칸씩 이동한 후 출력
풀링은 학습 상수가 없지만 스트라이드 커널을 동시에 학습함.
풀링+합성곱을 하나의 레이어로 대체. 해상도 저하로 인한 정보 손실이 적은 편. 학습 가능한 Conv연산으로 가중치 W를 학습 후 영역 전체를 가중합


CNN 기반 모델 변천사
AlexNet-VGG16-ResNet
합성곱 층과 풀링층 번갈아가면서 하다가 분류층은 FC layer와 출력층(softmax로 0~1로)

AlexNet
5개의 합성곱 + ReLU 비선형 활성화 + 맥스 풀링 + 3개의 완전연결계층 = 8계층
원-핫 방식으로 학습 
출력: 1x1024 벡터를 만들고 24개는 버려서 1000개로 씀
합성곱층 -> 풀링층 -> ... -> 완전 연결층1 -> 완전 연결층2 -> 출력층(softmax)
출력 해상도 = [입력 사이즈 - 커널(필터) 사이즈 + 2*(패딩)] / 스트라이드 +1
출력 메모리 용량 = 활성화 값 개수 * 4 byte = C * H' * W' * 4byte
상수의 개수 = 출력 채널 수 * 입력 채널 수 * K^2(필터 웨이트) + 출력 채널 수 (바이어스 웨이트)
FLOPs(연산량) = 총 연산 = 출력 원소 수 * 출력 원소별 연산
= (H' * W') * (Cin * K * K * Cout)


VGG-16 기준(16은 레이어의 개수를 말함)
- 5개 합성곱 블록(각 블록당 합성곱 - ReLU 구조 반복)
- 각 블록당 맥스 풀링
- 3개 연결층 레이어
- ReLU 비선형 활성화
- 총 16개의 합성곱/연결층 레이어
- 최종 소프트맥스 수행

VGG-16 -> Vgg-19 
큰 커널을 쓸 필요 없다. 작고 단순한 필터를 깊게 쌓으면 성능이 향상
합성곱을 연달아서 적용 
합성곱 5x5 -> 합성곱 3x3 2개 
수용영역은 같은데 파라미터의 연산 FLOPs가 줄어들고 깊이가 깊어짐 
해상도를 줄일 때마다 채널을 늘려 레이어별 연산량 차이를 줄임 

ResNet
합성곱 블록(VGG 유사)과 잔차(Residual. 블록 입력을 그대로 출력에 더해줌) 블록
Inception 모델에서 차원 축소로 활용된 1x1 합성곱을 적용, 연산 효율 개선
배치 정규화 방식: 10개 레이어 이상을 학습 가능
레이어를 많이 넣었더니 트레이닝 에러가 더 높음 - 과접합을 했으면 트레이닝 에러가 낮아야 하는데 높다는 건 트레이닝이 안 된다는 뜻. 이를 해결하기 위한 잔차 블록. 작은 모델(10+레이어)보다 성능이 안 나올 것 같으면 작은 레이어의 추정값(입력값)을 그대로 후속 레이어에게 넘겨서 작은 레이어의 성능을 보장함.
입력 path가 2개임. Output = F(x) + x 인데 학습이 잘 안 되면 F(x) =0으로 두고 x 출력 

보틀넥 잔차 블록: 앞 뒤로 1x1짜리를 넣고 수용 영역을 가운데에 배치
입력할 때 채널을 축소하여, 연산 효율을 높이고, 출력할 때 채널을 크게 만들어 입출력 해상도 일치시킴. 깊이가 2개였던 걸 3개로 만드니 연산 성능 좋음. 보틀넥 잔차 블록 덕에 100 레이어 이상 쌓을 수 있음 

stem 구조: 여러 개의 FC를 제거하고 전역 평균 풀링을 사용하여 마지막 FC 1개만 남김. 해상도를 평균 내서 채널만 남기는 것.
Stem(입력부) 구조는 잔차 블록(Residual Block)이 시작되기 전, 입력 데이터의 해상도를 줄이고 저수준의 특징(선, 색상 등)을 추출하는 첫 번째 관문.

MobileNet
존 합성곱은 공간(HxW)와 채널(C)를 동시 처리하여 연산량이 과도하게 요구
깊이별 합성곱 / 화소별 합성곱 나눠서 처리
깊이별 합성곱: 각 채널별 독립적 3x3 합성곱 수행. 연산량 9CHW
화소별 합성곱: 1x1 합성곱을 채널방향으로 적용. C^2HW
일반 합성곱: 9C^HW

CNN의 한계: 순서 정보를 반영 못함. 긴 거리 의존성 고려 부족. 복원 시 위치 정보 손실(pooling/stride)

CNN의 한계
순서 반영 어려움, 긴 거리 의존성 고려 부족, 픽셀 단위 복원 한계(위치 정보 손실)


RNN(Recurrent Neural Nets)
순차적 데이터를 처리
이전 데이터를 hidden state에 저장해서 남기고, 새로운 데이터와 합쳐서 다음 단계에 전달
input chars: 학습하려는 문자열. 원-핫 인코딩으로 input layer에 들어감
input layer: 0과 1로 된 벡터. W_xh입력 -> 은닉으로 변환
Hidden layer: 현재 입력에 이전 상태의 은닉을 합쳐 만든 내부 메모리. 이전까지의 문맥을 담고 다음 단계로 전달. W_hh: 이전 은닉 -> 현재 은닉
output layer: hidden state를 출력 벡터로 변환. 각 숫자는 다음 문자가 될 확률을 계산하기 위한 점수. W_hy 은닉 -> 출력 변환 
target chars: 각 시점에서 예측해야 하는 정답. 이 정답과 output layer 확률을 비교한 오차로 가중치 업데이트
계속 반복 

RNN 셀: 은닉층에서 활성화 함수를 통해 결과를 내보내는 역할
x: 입력층의 입력 벡터
y: 출력층의 출력 벡터
셀: 이전 값을 기억하는 메모리 역할 수행
시계열 의존성 : ht가 이전 상태 ht-1에 의존
은닉상태(hidden state): 메모리 셀이 출력층 방향 또는 다음 시점인 t+1의 자신에게 보내는 값 
순수 RNN : 선형 변환, 바이어스를 모델상수/비선형 (tanh 하이퍼볼릭 탄젠트) 함수 추가로 구성된 단순한 형태
시퀀스 입력 - 단일 출력 : x1, x2, x3…를 입력하면 y나옴
단일 입력 - 시퀀스 출력: x를 입력하면 y1, y2, y3…가 나옴
역전파 시 선형가중치 W가 기울기 계산 시 계속 곱셈으로 반영됨. 기울기 폭발/소실 발생
기울기가 폭발할 것 같으면 절삭 -> 원래 적용해야 할 기울기 값과 다름
기울기 소실은 해결법 없음 -> 다른 대안 모델 사용


대안 모델 LSTM(Long Short-Term Memory)
cell state: 중요한 정보를 유지/기억
gate: 정보 흐름 제어
입력 게이트: 새로운 정보 저장 
망각 게이트: 데이터를 얼마만큼 지울 것인지
출력 게이트 : 필요한 정보를 다음 은닉 상태로 출력
누적 효과로 인해 과거 정보 희석

긴거리 의존성 어텐션
어텐션 메커니즘: 픽셀 거리와 상관 없이 유사한 패치가 이미지에 존재할 때, 관련 높은 패치와 관련 낮은 패치 정보를 최종 결정에 반영하자
쿼리: 집중 대상. 질의 대상 (입력 토큰)
키: 다른 패치. 특성 (입력 내 기타 토큰)
값: 키 패치의 정보
어텐션: 쿼리와 키의 유사도(확률 분포 형태)
출력: 어텐션으로 가감된 값의 총합 
어텐션 메커니즘의 상수는 4개: 쿼리를 뽑는 상수, 키를 뽑는 상수, value를 뽑는 상수, 그리고 어텐션(유사도)
쿼리와 키의 내적을 디멘션으로 나누고 밸류를 곱한 뒤 softmax를 수행하면 어텐션 값


셀프 어텐션: 사람이 레이블을 하지 않아도 유사한 패치끼리 묶어내는 구조를 만들어냄. 하나의 입력 안에서 쿼리/키/값 패치 정보를 정의. 같은 이미지 내 유사도를 반영. 입력 내부 패치간 연결망 구축 -> 클러스터링 효과 

교차 어텐션: 둘 이상의 이종 데이터에서 쿼리/키/값 패치 정보를 정의. 이종 데이터 간 유사도 반영. 서로 다른 입력간 연결망 구축 

Vit 위치 인코딩: 전 트랜스포머(ViT)의 셀프 어텐션은 이미지 전체의 패치 간 관계를 한 번에 계산하므로, CNN보다 넓은 수용 영역을 바탕으로 이미지 내 먼 거리의 요소들 간 연관성인 긴거리 의존성을 효과적으로 학습. 
이미지를 이미지 토큰 집합으로 변환
위치 인코딩으로 패치 토큰의 순서를 학습에 반영 
어텐션 메커니즘은 supervision(정답, 라벨)이 없어도 됨
어디를 봐야 정답을 잘 맞추는지를 모델이 최종 정답(분류 라벨)만 가지고 스스로 역전파를 통해 알아냄
장기적 맥락에서 탁월
데이터 순서를 반영하기 위해 위치 인코딩을 적용
1. 학습 가능한 위치 인코딩: 위치마다 학습 가능한 벡터를 하나씩 만들어 다른 가중치(W)들처럼 학습
처음엔 완전 랜덤한 숫자로 시작해서, 학습 과정(역전파)을 거치면서 이 숫자들 자체가 점점 최적의 값으로 조정. 해상도가 바뀌면 다시 학습 필요 
2. 사인파 인코딩: 주파수를 낮은 데서 높은 데까지 올려가면서 sin/cos 값을 나열하여 긴 형태의 위치 벡터 형태로 출력 → 저주파는 대략적인 위치를, 고주파는 정밀한 위치를 보여줘서 다 합치면 표현력이 좋음. 고정이라 데이터/과업에 특화된 방식이 아님 
3. 상대 위치 인코딩: 절대 위치가 아닌, 상대적 위치를 인코딩
attention은 쌍으로 비교하는 연산이므로 ‘이 둘은 2칸 떨어져 있다’는 관계 정보가 attention 계산에 더 직접적으로 유용. 해상도 변화에 적용 가능. 절대적 위치 고려가 어려움. 

ViT 인코더 내부 구조
정규화 - 다중헤드 어텐션 - 정규화 - 연결층(MLP)
정규화(Normalication): 입력을 균일하게 맞춤
다중헤드 어텐션(Multi-Head Attention): 여러 관점에서 패치 간 관계를 학습(예: 어떤 패치는 형태, 다른 패치는 색, 또 다른 패치는 위치)
연결층(MLP): 어텐션 정보를 조합, 변환해 더 풍부한 특징 생성. 최종 예측 수행.

ViT vs ResNet
ViT는 거대 데이터세트를 학습한 이후에 우수함 

증류학습: 학생 ViT 모델은 학습 가능한 토큰을 추가로 입력 받아 선생님 CNN의 logit 출력과 동일하게 예측하도록 학습됨 

Swin Transformer
1) 내부 윈도우를 지정해서 그 지역의 어텐션에 집중함
2) 그 다음에 윈도우를 비껴가게 자르고 내부에서 어텐션 구함
1)과 2)가 중첩되면서 최종적으로 이미지 전역 효과

단순 선형 모델 -활성화 함수-> 비선형성
활성화 함수 종류
시그모이드 : 0~1 : 출력이 0이거나 1인 구간에서 역전파 신호가 0이 되어 신경망이 더 이상 학습을 못함. 기울기의 평균이 양수로 치우쳐 학습 비효율 발생 
Tanh: [-1, 1]: 출력이 -1이나 1에 가까워져 신경망이 더 이상 학습 불가. exp 연산 때문에 계산 비용 큼 
ReLU: max(0,x) : 죽은 뉴런 문제 → 입력이 계속 음수면 뉴런이 0만 출력. 0을 기준으로 비대칭 
Leaky ReLU: f(x) = max(0.01x, x): 
ELU : 포화구간을 넣어 비선형성을 강조함

데이터전처리
이미지 조건을 일치
학습/검증/테스트에 모두 동일하게 적용
- 이미지 해상도
- 색상(RGB, BGR, Grey 등)
- 밝기
- 정규화: 평균 0, 표준편차로 1 

모델 상수 초기화
0으로 초기화하기 -모든 출력 0이 되어 학습 x
임의로 초기화하기 - 가우시안 분포 → 값이 너무 크거나 작아지는 걸 막을 수 있음. 너무 깊은 모델에서는 역전파 기울기를 구하는 과정에서 W를 계속 곱하면서 기울기가 0으로 수렴하거나 폭발 
자비에 초기화 - std = 1/√dim. 모델 상수의 분산이 입력 차원과 관련되도록 설계하면, 선형 연산 이후 출력의 분산 = 입력의 분산.출력값의 분산이 커서 0이 되지 않음. 다만 tanh 사용해서 연산 어려움 
허 초기화 - 자비에 초기화 + ReLU. ReLU를 쓰면 좌우 대칭이 깨져서 자비에르 초기화가 잘 안 맞음. 그래서 가중치 초기 분포의 분산을 2 * 입력차원에 맞춰서 설정. 비대칭적 분포에서도 분산이 유지되도록함. ReLU를 쓴다면 He 초기화 쓰기. 

ResNet: 전 층의 기울기 전달
잔차 연결: 입력을 출력에 더해주는 지름길로 네트워크가 전체를 새로 배우지 않고 변화량만 학습하도록 도와줌
ReLU를 사용하는 구조이므로 He 초기화를 사용
Var(x + F(x)) = Var(x)을 유도함 → 초반에는 F(x)를 0으로 만들도록 함. 입력 그대로 나가게끔 유도
사실상 초반에는 skip connection에만 의존, 안정적 학습을 유도
초기엔 입력=출력이라 분포가 안정해서 학습이 안전하게 출발 

모델 정규화
성능이 오르지 않으면 과적합
정규화로 검증 오차를 줄여야 함. 
정규화: 모델 복잡도를 제어해 훈련 성능과 검증 성능의 차이를 줄이는 방법
검증 오차: 모델이 학습하지 않은 새로운 데이터에서 보이는 실제 성능 지표 

방법1. 가중치 감소
L2 정규화(Ridge): 큰 가중치에 제곱으로 패널티 -> 극단적으로 큰 값 방지. 모든 가중치가 골고루 작아짐
L1 정규화(Lasso): 모든 가중치에 절댓값 크기만큼 동일하게 패널티. 중요하지 않은 가중치는 완전히 0이 됨
L1+L2 = Elastic net: 변수가 많고 상관관계가 높을 때 효과적  

방법2. 드롭아웃(CNN이 아니라 FCN에서 사용)
일부 뉴런을 확률적으로 끔. 특정 뉴런/특정에 과도하게 의존하지 않게 함. 여러 작은 모델을 합친 것과 비슷한 효과(앙상블 방식). 다만 테스트 시이는 뉴런을 전부 사용하는데 그대로 쓰면 학습할 때보다 출력 크기가 2배라서 학습-추론간 분포 차이가 생겨 성능 저하.
inverted 드롭아웃 사용: 뉴런의 출력을 1/(1-p)배 스케일링해서 출력을 키움. 
기존 방식: 1-p를 출력에 곱하여 평균치를 맞췄기에 테스트 시 추가 연산이 필요 했음. 

학습 안정성 - 학습률 조정
-계단식 변경: 많이 사용. Loss가 정체되는 구간마다 학습률을 떨어뜨림. 학습 곡선이 불안정.
-코사인 변경. 처음엔 크게, 나중엔 미세하게 조정
-선형 변경: 처음엔 크게 배우고 끝날수록 일정하게 줄여서 수렴. 사전학습/미세조정에서 주로 쓰임 
-역제곱 변경: 처음엔 크게, 이후에 느리게
-일정값 유지: 동일한 속도로 학습. 데이터가 많고 과적합 위험이 없을 때 활용 

빠른 종료-과적합 방지

하이퍼 파라미터 선택
그리드 탐색: 하이퍼 파라미터 후보들을 격자처럼 전부 조합
랜덤 탐색: 하이퍼 파라미터 공간에서 무작위로 값을 선택해 탐색함. 

학습률에 따른 손실곡선 체크
초반 손실값이 유지: 초기값 문제
손실이 크게 떨어지지 않고 유지: 학습률 줄이기 시도
학습률 변경을 적용했는데 학습이 진행되지 않음: 정체가 오기 전에 너무 일찍 학습률을 줄임 
정확도가 증가할 경우: 계속 학습
학습/검증 정확도가 크게 떨어진 경우: 과적합
학습데이터/검증 데이터 결과의 차이가 매우 적다면: 모델의 힘이 너무 약한 것. 큰 모델을 도입할 것

1. 코사인 유사도란?
두 벡터(숫자 뭉치)가 "얼마나 같은 방향을 보고 있는지"를 나타내는 값이에요. 화살표 두 개가 있다고 생각해보세요.
완전히 같은 방향 → 값 1 (가장 비슷함)
서로 관계없는 방향(직각) → 값 0
완전히 반대 방향 → 값 -1 (가장 다름)
2. CLIP이 하는 일
CLIP은 이미지와 텍스트를 각각 숫자 벡터로 바꿔주는 두 개의 인코더(변환기)를 가지고 있어요.
이미지 인코더: 사진 → 벡터
텍스트 인코더: 문장 → 벡터
예를 들어 "강아지 사진"과 "a photo of a dog"라는 문장이 있으면, 이 둘을 각각 벡터로 바꿔요.
3. 학습 목표
짝이 맞는 이미지-텍스트 쌍 (강아지 사진 ↔ "a dog" 문장) → 두 벡터의 코사인 유사도가 1에 가깝게 되도록 학습
짝이 안 맞는 쌍 (강아지 사진 ↔ "a cat" 문장) → 유사도가 낮아지게(0이나 음수 쪽) 학습
즉, "이 사진과 이 설명이 잘 맞으면 벡터도 같은 방향을 보게 만들어라"가 CLIP의 핵1단계: 배치(batch) 안에 여러 쌍이 동시에 들어와요

CLIP은 한 번에 이미지 1개, 문장 1개만 보고 학습하지 않아요. 보통 한 번에 여러 개(예: 4개)의 이미지-문장 쌍을 동시에 넣어요.
예를 들어:
이미지1(강아지) - 문장1("a dog")
이미지2(고양이) - 문장2("a cat")
이미지3(자동차) - 문장3("a car")
이미지4(나무) - 문장4("a tree")
2단계: 모든 조합의 코사인 유사도를 계산해요
이미지 4개 × 문장 4개 = 총 16개의 조합에 대해 전부 코사인 유사도를 계산해요. 표로 그리면 이렇게 돼요:

	문장1(dog)	문장2(cat)	문장3(car)	문장4(tree)
이미지1(강아지)	0.9	0.2	0.1	0.15
이미지2(고양이)	0.3	0.85	0.1	0.2
이미지3(자동차)	0.1	0.15	0.88	0.1
이미지4(나무)	0.2	0.1	0.2	0.92

여기서 굵게 표시된 대각선(진짜 짝)이 가장 높아야 정답이에요.심 아이디어예요.

3단계: 왜 softmax를 쓸까?
각 이미지 입장에서, "내가 4개 문장 후보 중 어떤 걸 골라야 할까?"를 정답을 맞히는 분류(classification) 문제로 바꾸는 거예요.
이미지1(강아지) 줄을 보면: [0.9, 0.2, 0.1, 0.15] 라는 4개 숫자가 있죠. 이걸 softmax에 넣으면, 이 4개 숫자를 합이 1이 되는 확률로 바꿔줘요. 값이 클수록 확률도 커져요.
즉, softmax는 "이 4개 후보 중에서 정답 문장일 확률은 각각 몇 %야?"로 바꿔주는 함수예요.

4단계: 정답과 비교해서 loss 계산 (Cross-Entropy)
softmax를 거치면 "이미지1은 문장1일 확률 70%, 문장2일 확률 15%..." 이런 식으로 나와요. 진짜 정답은 문장1이니까, "정답 확률이 100%에 가까울수록 좋다"는 기준으로 오차(loss)를 계산해요. 이게 바로 Cross-Entropy Loss예요.
정답 확률이 1(100%)에 가까우면 → loss가 작음 (좋음)
정답 확률이 낮으면 → loss가 큼 (나쁨, 더 학습 필요)

5단계: 양방향으로 계산해요
재밌는 점은, 이걸 두 방향으로 다 해요:
이미지 → 문장 방향 (각 이미지가 어떤 문장을 고를지)
문장 → 이미지 방향 (각 문장이 어떤 이미지를 고를지)
이 두 loss를 평균 내서 최종 loss로 사용해요.

dim=1 (가로축, 각 행끼리 계산)
이미지1 행을 보면: [0.9, 0.2, 0.1, 0.15] → 이 4개 숫자를 가로로 쭉 훑으면서 softmax 계산
즉, "이미지1 입장에서, 4개 문장 후보 중 어떤 게 정답일 확률이 높은가?" → 이미지 → 텍스트 방향
dim=0 (세로축, 각 열끼리 계산)
문장1 열을 보면: [0.9, 0.3, 0.1, 0.2] (위에서 아래로) → 이 4개 숫자를 세로로 쭉 훑으면서 softmax 계산
즉, "문장1 입장에서, 4개 이미지 후보 중 어떤 게 정답일 확률이 높은가?" → 텍스트 → 이미지 방향

CLIP의 제로샷(Zero-shot) 이미지 분류 메커니즘 동작 절차
분류할 텍스트 카테고리 리스트를 텍스트 임베딩으로 변환한 뒤, 쿼리 이미지 임베딩과 코사인 유사도가 가장 높은 카테고리를 찾는다

#### Vision-Language Model(VLM)
SigLIP은 softmax 대신 sigmoid 기반 손실함수
기존 CLIP에서 사용한 대조학습의 한계 : 이미 충분히 거리가 먼 음성 데이터 쌍들에 대해서도 계속 거리를 벌리기 위해 학습 진행
SigCLIP: 일치하지 않는 음성 데이터에 제한된 영향만 받도록 손실함수 디자인을 고침. 최신 VLM에 널리 활용 
각 (이미지, 텍스트) 쌍을 독립적인 이진 분류 문제로 처리

멀티모달 정합(Multi-modal Alignment): 서로 다른 두 가지 이상의 모달리티 간의 공통된 임베딩 벡터 공간을 구성
서로 다른 모달리티 임베딩 간 유사도(연관성) 비교 가능 

CLIP 모델의 고급 응용
모달리티 변환을 위한 2가지 디자인
변환: 모달리티 A -> 모달리티 B
정합: 모달리티 A -> 정렬된 피쳐 공간 <- 모탈리티 B
정합을 통한 크로스모달 변환
멀티모달 정합 손실 함수: 멀티모달 데이터 사이에 정렬된 정도를 측정 
텍스트-이미지 간 정렬 정도 측정(손실함수로 사용됨)->유사도 최대화->backpropagation(역전파)->학습가능한 파라미터로 설정->Image-to-text(이미지 캡셔닝). 
텍스트-이미지 간 정렬 정도 측정(손실함수로 사용됨)->유사도 최대화->backpropagation(역전파)->미분가능한 이미지 구성으로 설정->학습가능한 파라미터로 설정->Text-to-X(Text-to-3D)
다양하고 구체적인 텍스트 생성, 이미지 편집, 3D 애니메이팅 아바타

토크나이저의 언어 편중 이슈
형태소가 복잡한 언어의 토큰화: 서브워드 단위로 쪼개지는 토큰 수가 크게 증가 

생성모델 기초
생성 모델링
데이터셋: 미지의 데이터 분포로부터의 샘플들
생성모델: 데이터셋으로부터 데이터 분포를 알아내는 과정
의미: 미지의 데이터 분포를 알 수 있다면 새로운 데이터를 샘플링 할 수 있다 
미지의 데이터 분포를 안다는 것은 실제 데이터를 생성하는 과정을 정확하게 안다는 것
미지의 데이터 분포가 실로 어떤 형태인지는 우리는 모름
목표: 실제 분포를 모르니 유사 모델로 근사 
실제 분포와 유사 모델간의 갭이 크면 애매한 이미지가 나오긴 함 

Diffusion model
영상 생성 모델
매커니즘: 노이즈로부터 점진적으로 노이즈를 제거하여 이미지를 구체화하는 생성 방식
학습법: 합성 노이즈를 입히고(인코더 통과하고 forward) 그 노이즈를 제거하는 과정(디코더 통과, backward)을 거쳐서 이미지 생성
노이지를 다 뿌리고 나면 가우시안 노이즈(정규분포, 간단한 분포)가 됨
이 노이즈를 제거하면서 노이즈를 예측하는 문제를 반복 학습 

Latent diffusion Model(LDM)
저차원 latent 임베딩(=압축된 특징 정보)으로 변환 후 diffusion 연산을 수행. 
연산 효율을 높임과 동시에 이미지 생성 품질 또한 향상 시킴 
1단계: 텍스트 특징 생성: 텍스트 입력을 함축하는 임베딩 값을 얻음
2단계: 텍스트 특징을 바탕으로 생성된 이미지를 점차 개선하여 고품질 이미지를 생성함 

#### 개인화
파운데이션 모델과 미세조정이 필요한 이유
방대한 데이터로 학습된 초대형 딥러닝 모델. 다양한 작업이나 범용적인 문제에 바로 적용 가능
최근에는 텍스트 뿐만 아니라 이미지, 오디오, 비디오 등의 다양한 입력 데이터를 처리할 수 있는 멀티모달로 확장
하지만 최신 정보나 특정한 작업/도메인에 최적화되어 있지 않아, 즉시 활용이 어려운 경우가 있음 
파인튜닝(미세조정): 추가 학습을 통해 이미 학습된 모델을 조금만 튜닝하는 것
MLLM(Multimodal Large Language Model) 가정에서 사전 학습된 모델에 프롬프팅을 통한 작업을 했을 때보다 더 좋은 퀄리티의 결과물을 생성
프롬프트에 넣는 예제보다 훨씬 더 많은 예제를 통해 학습 가능
프롬프트의 길이가 줄어들면서 토큰 개수 절약
응답하는 데에 걸리는 시간(latency) 단축

gradient(경사): 손실함수(loss) 미분을 통해 구한 기울기 
learning rate: 반영할 비율 손실함수가 큰 값일 때 미세하게 조정하기 어려우므로 뉴럴넷 모델에 작은 비율로 반영함. 
미세조정은 좋은 시작점에서 시작하기 때문에 작은 learning rate부터 보수적으로 시작해야 함 

프롬프트 디자인: 추가 학습 없이 사전학습된 모델의 예측 성능을 끌어올릴 수 있음. 프롬프트를 사람이 직접 설계해야 함. 성능 향상이 제한적 

프롬프트 튜닝: 학습 가능한 프롬프트로서 가상 토큰을 입력해 추가. 역전파를 통해 오직 가상 토큰에 대한 임베딩만 학습하고 나머지 모델은 고정. 사전학습된 모델은 고정되므로 지식 손실 없음. 적은 비용으로 새로운 데이터셋의 모델 학습 가능 

adaptor 모듈 추가 학습: 학습 가능한 작은 모듈(adapter)을 레이어마다 삽입하여 일부 파라미터만 학습하는 기법 
LoRA(Low-Rank Adaptation): LoRA는 레이어마다 저랭크 행렬(작은 모듈)을 삽입하여 전체 파라미터 중 일부만 효율적으로 학습하는 대표적인 PEFT(Parameter-Efficient Fine-Tuning, 대형 언어 모델(LLM)의 모든 매개변수를 수정하는 대신, 아주 적은 일부 매개변수만 학습하여 비용과 자원을 아끼는 미세 조정 방식) 기법

Knowledge Distillation지식 증류 (Teacher-Student 학습)
사전학습된 고성능 모델의 지식을 타겟 모델에게 압축해서 전달 
선생님 모델을 모방하도록 가벼울 모델을 학습
선생님 모델이 예측한 soft-label값과 학생 모델의 예측값이 가까워지도록 학습 유도 
합성 데이터는 데이터 취득이 어려운 문제에서 유용 
합성 데이터 활용시, 라벨 품질의 불일치(라벨 정규화, 클래스 사전, 교차 모델 검증, 휴먼 검수로 개선)와 할루시네이션(정교한 프롬프트, 후처리 refiner, 사실성 검증 모델, 실데이터 혼합으로 개선) 주의

언어모델(LLM)+검색증강생성(RAG)
유연성:추가 학습 없이 최신 정보 제공
개인화: 검색과 언어 모델의 합성으로 개인 맞춤형 답변 가능
정확성: Verification을 통한 환각 현상 감소
