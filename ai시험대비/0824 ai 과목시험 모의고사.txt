SigCLIP: 일치하지 않는 음성 데이터에 제한된 영향만 받도록 손실함수 디자인을 고침. 최신 VLM에 널리 활용

Q3. CNN 공간 구조
CNN이 이미지 데이터를 다룰 때 갖는 공간 구조적 특징
CNN은 2D 격자 형태의 이미지 구조를 유지하여 주변 픽셀 간 공간적 연관성(Spatial Structure)을 잘 보존
CNN은 커널 공유(Weight Sharing) 기법을 통해 이미지 내 물체의 위치가 이동해도 이를 잘 포착하는 위치 불변성(Translation Invariance)을 가짐
필터를 원본에서 이동시키면서 입력 값과 곱하고 합산하여 특징 맵(feature map)을 뽑아냄
입출력 해상도를 유지하고 싶다면 1. 제로패딩 2. 가까이에 있는 값 채워넣기
가중치 w와 bias가 합성곱 레이어의 상수
비선형 블록(Conv+ReLU)을 끼워 모델 상수를 증가시킴 
pooling: 해상도를 작게 만들어 연산량 줄이기.위치 변화 강건성.
맥스 풀링: 모델 상수 없음.
스트라이드 합성곱: 필터를 스트라이드 값 S칸씩 이동. 커널 동시 학습.

Q6. CNN과 ViT
CNN은 국소적 수용장(Local Receptive Field)을 통해 주변 픽셀 간 정보를 주로 추출
ViT는 이미지를 일정 크기의 패치(Patch) 단위로 나누어 트랜스포머 인코더에 입력
ViT는 셀프 어텐션을 통해 이미지 전체 영역 토큰 간의 관계성을 동시에 고려. 이미지 내 먼 거리의 요소들 간 연관성인 긴거리 의존성을 효과적으로 학습. 
ViT과정
1) 이미지를 작은 패치로 나눔
2) 각 패치를 1D로 Flatten
3) Learnable position embedding으로 이미지 내에서 각 패치의 위치 민감 정보를 추가함. 
4) Transformer encoder: 패치 처리
5) MLP HEAD를 통해 분류 작업 수행.
ViT 인코더 내부 구조
정규화(입력을 균일하게) - 다중헤드 어텐션 - 정규화 - 연결층(MLP)(어텐션 정보를 조합, 변환하여 최종 예측)

Q8. Diffusion 이미지 생성

2) 텍스트 특징을 바탕으로 생성된 이미지를 점차 개선하여 고품질 이미지를 생성함

Q10. LSTM 게이트
RNN에서 역전파 시 기울기 소실이 되는 문제를 해결하기 위해 gate 추가 
short-term information을 저장하는 hidden state
long-term information을 저장하는 cell state
cell state는 정보를 읽고, 지우고, 기록할 수 있음 
Forget gate: 이전 cell state에서 무엇을 버리고 기억할지 결정
Input gate: 새 정보 중 얼마를 cell state에 쓸지 결정
output gate: cell state 중 얼마를 hidden state로 보낼지 결정 
게이트는 동적으로 계산되고 각 요소는 열림(1), 닫힘(0), 그 사이의 값으로 설정됨 



Q11. P-value 해석
P-value: 귀무가설(H_0. 차이가 없다, 우연이다)이 참이라는 전제하에, 관찰된 결과 이상의 극단적인 값이 나올 확률이다.
작을수록 관계가 있다고 봄. 유의한 관계.
p ≥ 0.05: 우연히 발생했을 확률이 5% 이상으로 높아 관계가 있다고 증명하기 어려움.
Std.Error(표준오차): 표본을 뽑을 때마다 흔들리는 값. 작으면 좋음
t-statistic: 계수 추정치가 0(=효과 없음)으로부터 표준오차 몇 배만큼 떨어져 있는가. 높을 수록 우연이 아니므로 좋음.

Q14. Seq2Seq와 Transformer
Seq2Seq(RNN 기반) 모델 대비 트랜스포머(Transformer)가 가지는 결정적인 구조적 장점은?
셀프 어텐션을 활용하여 입력 토큰 전체를 병렬 처리(Parallelization)할 수 있다.
Seq2Seq: 2개의 LSTM 이용. 한 LSTM은 입력 시퀀스를 한 타임스텝씩 읽어서 고정된 차원의 큰 벡터 표현을 얻음(Encoder). 다른 LSTM은 앞에서 얻은 벡터로부터 출력 시퀀스를 생성함(Decoder) 
Seq2Seq 모델은 인코더와 디코더가 하나의 통합 네트워크로 연결.
디코더에서 발생한 오차는 역전파 과정을 통해 입력을 처리한 인코더까지 전달, 전체 네트워크가 End-to-End로 동시에 최적화 
Seq2Seq의 한계: bottleneck problem: 마지막 고정 길이 벡터 하나에 모든 문장의 의미를 압축하다 보니 정보 손실이 생김

Transformer: Self-Attention을 핵심 메커니즘으로 하는 신경망 구조 
encoder-decoder 구조로 설계됨
Decoder: 트랜스포머의 디코더는 여러 개의 디코더 블록들을 쌓아 올려 만든 구조. 4개 구조로 구성
Masked self-attention(multi-head), Add&Norm(Residual Connection + Layer Normalizaion), Feed-Forward Network(비선형 변환), Add&Norm(Residual Connection + Layer Normalizaion)
언어 모델처럼 단방향 문맥만 활용
Encoder: 양방향 문맥 모두 활용 가능. 입력 문장을 의미적 표현으로 변환. 각 반 단어가 양방향 문맥을 모두 반영한 벡터로 인코딩됨. Decoder와의 차이점은 self-attention에서 masking을 제거한 것 뿐.

Q17. 결정계수 R^2

회귀의 손실함수를 측정할 때 사용
유의성 검정 - 결정계수 R^2 = 1 - RSS/TSS



Q18. 경사하강법
경사하강법(Gradient Descent)에서 파라미터 업데이트 시 기울기(Gradient)의 역할
손실함수(Loss Function)의 값이 가장 가파르게 증가하는 방향을 알려준다
gradient(경사): 손실함수(loss) 미분을 통해 구한 기울기 
MSE를 0으로 만드는 최적의 모델(w와 b)찾는 법이 최소 제곱법(LSM)
ㄴ 정규 방정식(수학 공식으로 한 번에 푸는 법), 경사 하강법 2가지
경사 하강법: 비용 함수(MSE)의 기울기가 0이 되는 지점이 가장 비용이 낮은 지점이다. 기울기, 이터레이션, 에포크, 학습률, 오버 슈팅, 배치, 허용 오차 등 구성.

Q20. 로지스틱 회귀의 변환
선형 결합 값(z = w^T x + b)을 0과 1 사이의 확률값으로 변환하기 위해 사용하는 함수는 sigmoid 함수 
로짓(Logit) 변환 : 0과 1 사이의 확률값 p를 -infty에서 +infty 범위를 갖는 실수 값으로 변환
로짓(Logit)의 역함수 시그모이드 : -infty에서 +infty 범위를 0과 1사이의 확률값으로 변환 
로지스틱 회귀는 선형 회귀의 문제점(0~1 벗어남, 이상치 민감, 다중 분류 못함)을 해결
이진 교차 엔트로피 : 선형 회귀 + 시그모이드 함수 + 이진 교차 엔트로피(BCE). 경사 하강법을 사용하여 BCE 비용을 최소화하는 방향으로 w와 b를 계속 업데이트. 이진 분류
소프트맥스(Softmax) 함수: 소프트맥스 회귀 = 선형 회귀 + 소프트맥스 함수 + 범주형 교차 엔트로피(CCE, Categorical Cross-Entropy). 다중 분류

Q22. 선호 학습: 정답이 없는 개방형 테스크
DPO(Direct Preference Optimization)와 같은 선호 학습(Preference Learning)의 특징

CNN과 ViT의 차이점 
1. 이미지를 바라보는 방식 (연산 메커니즘)CNN (지역성 중심): 이미지를 조각(커널) 단위로 훑으며 가까운 픽셀 간의 관계(Local 특징)를 먼저 학습합니다. 얕은 층에서는 선이나 색상을, 깊은 층으로 갈수록 전체적인 형태를 이해합니다.ViT (전역성 중심): 이미지를 바둑판처럼 조각(패치)으로 쪼갠 뒤, 모든 패치 간의 관계(Global 특징)를 한 번에 계산(Self-Attention)합니다. 첫 레이어부터 이미지 전체의 맥락을 파악할 수 있습니다.
2. 귀납적 편향 (Inductive Bias)CNN (높음): "가까운 픽셀끼리 연관성이 높다"는 시각 데이터의 특성이 모델 구조 자체에 이미 반영되어 있습니다. 이 덕분에 적은 데이터로도 빠르게 기본 성능을 냅니다.ViT (낮음): 시각 데이터에 대한 아무런 사전 지식 없이 학습을 시작합니다. 픽셀 간의 위치 관계조차 스스로 학습해야 하므로, 제대로 성능을 내려면 압도적으로 많은 양의 데이터가 필요합니다.


GoogLeNet 및 ResNet 등 현대적인 CNN 분류 모델에서 네트워크 마지막 단의 여러 FC(Fully Connected) 레이어 대신 전역 평균 풀링(GAP, Global Average Pooling)을 사용하는 주된 이유로 가장 적절한 것은 무엇인가?
A.
파라미터 수의 폭증을 막아 과적합을 방지하고, 다양한 입력 해상도에 가변적으로 대응할 수 있게 한다.(내 답변)
정답
기존 FC 레이어는 파라미터가 매우 많아 과적합 및 파라미터 비중 상승의 원인이었으나, GAP는 각 채널 전체의 평균값 1개씩을 추출하므로 파라미터가 0개이며 입력 해상도가 변해도 고정된 채널 차원의 벡터를 얻을 수 있습니다.



교차 어텐션(Cross-Attention)은 쿼리(Query)를 한 도메인(이미지)에서, 키(Key)와 밸류(Value)를 다른 도메인(텍스트)에서 가져와 공통 임베딩 공간상에서 두 이종 데이터 간 어텐션 가중치를 산출합니다.


학습 진행 중 훈련 손실(Train Loss)과 검증 손실(Validation Loss)의 차이가 매우 작게 유지되면서 더 이상 성능이 오르지 않을 때, 우선적으로 고려해야 할 조치는 무엇인가?
B.
모델의 용량(Capacity) 및 크기 확대
정답
훈련 손실과 검증 손실의 차이가 거의 없는데 성능이 높지 않다면 모델의 표현력(Capacity)이 부족한 상태를 의미하므로, 더 깊거나 넓은 모델을 도입하여 학습시켜야 합니다.




자비에르(Xavier/Glorot) 가중치 초기화에서 가중치의 분산을 설계하는 수학적 도출 과정에서의 핵심 전제 조건으로 올바른 것은 무엇인가?
C.
활성화 함수가 원점 주변에서 대칭이며 선형에 가깝게 작동하여 입출력의 분산이 유지된다는 가정
정답
자비에르 초기화는 활성화 함수가 원점에 대칭이고 선형적이라는 가정(예: Tanh, Linear) 하에 입출력의 분산을 일정하게 유지하도록 유도되었습니다. 음수를 0으로 잘라내는 비대칭적 ReLU에는 이 가정이 깨져 He 초기화가 선호됩니다.

출력 분산이 0으로 수렴하면 신호가 소실되므로, 입출력 분산을 일정하게 '유지'하는 것이 자비에르 초기화의 목적입니다.



미니배치 크기(Batch Size)를 작게 설정했을 때 학습 파이프라인 관점에서 얻을 수 있는 주요 정규화(Regularization) 효과는 무엇인가?
작은 배치 사이즈는 매 스텝 그라디언트 추정에 노이즈를 추가하여 손실 함수의 평평한 최적점(Flat Minima)에 도달하도록 돕고 일반화 능력을 향상시킨다
정답
작은 배치 사이즈는 데이터 샘플링의 확률적 노이즈(stochastic noise)가 커져 뾰족한 최적점(sharp minima)을 피하고 일반화 성능이 좋은 평평한 최적점(flat minima)으로 빠져나가는 정규화 효과를 제공합니다.





이미지 전처리(Data Preprocessing) 단계에서 각 입력 채널의 픽셀 값을 평균 0, 표준편차 1로 표준화(Standardization)해주는 핵심적인 최적화 목적은 무엇인가?
손실 함수 지형(Loss Landscape)의 등고선을 원형에 가깝게 만들어 경사하강법 적용 시 진동을 줄이고 빠르게 수렴하도록 하기 위해
정답
특징(Feature) 간 스케일 차이가 크면 손실 함수 지형이 한쪽으로 길쭉한 타원형이 되어 경사하강법 시 진동(oscillation)이 심해집니다. 표준화를 거치면 지형이 원형에 가까워져 학습률을 안정적으로 크게 잡고 빠르게 수렴할 수 있습니다.


지시 함수 $I$는 조건이 참이면 1, 거짓이면 0이라는 이분법적 산출값(0 또는 1)만을 반환합니다. 연속적인 확률값을 반환하지 않습니다




선형회귀 결과표에서 특정 독립변수의 회귀계수(Coefficient) 크기가 0.0001로 0에 매우 가까울 때, 이 변수와 종속변수 간의 관계에 대한 올바른 해석은 무엇인가?
계수가 0에 가깝더라도 p-value가 0.05 미만이면 통계적으로 유의하다.
정답
계수의 절대적 크기는 측정 단위에 따라 달라지므로 관계의 유의성은 계수 크기가 아니라 p-value를 통해 판단해야 합니다.



로지스틱 회귀 모델 학습 결과, 특정 독립변수 x_1에 대한 회귀계수 $\hat{\beta}_1 = 0.5가 도출되었을 때 이 계수의 수학적 의미로 올바른 것은 무엇인가?
입력 변수 x 1이 1단위 증가할 때 로그 오즈(Log-odds)가 0.5만큼 증가한다.(내 답변)
정답
로지스틱 회귀의 로짓 변환식을 통해 로그 오즈 $\log\left(\frac{p}{1-p}\right)$는 선형식 형태를 띠므로 계수만큼 직렬 증가합니다.




하나의 은닉층을 가진 얕은 신경망과 관련된 '보편적 근사 정리(Universal Approximation Theorem)'의 핵심 주장 내용으로 옳은 것은 무엇인가?
하나의 은닉층에 충분히 많은 노드가 있다면 임의의 연속함수를 정밀 근사할 수 있다.
정답
은닉층이 1개라도 충분한 수의 히든 유닛이 주어지면 조각별 선형 구간을 세밀하게 분할하여 임의의 연속함수를 원하는 정밀도로 근사 가능합니다.



심층 신경망 학습 시 역전파(Backpropagation) 알고리즘이 경사하강법의 계산 효율성을 극대화하는 핵심 원리는 무엇인가?
출력층의 그래디언트를 이전 층으로 전달하며 이미 계산된 미분값을 재사용하기 때문이다.
정답
출력(손실)에서부터 입력 방향으로 연쇄법칙을 적용하여, 뒤쪽 레이어에서 계산해 둔 미분 중간 결과를 앞쪽 레이어 계산 시 재활용하므로 중복 연산을 방지합니다.



다중 선형회귀(Multiple Linear Regression)에서 특정 독립변수 $x_1$의 회귀계수 $\hat{\beta}_1$을 올바르게 해석한 설명은 무엇인가?
다른 모든 독립변수의 값을 일정하게 고정한 상태에서 x 1이 1단위 증가할 때 y의 평균적인 변화량이다.
정답
다중 회귀계수는 다른 제3의 독립변수들의 영향을 통제(고정)한 상태에서 x 1이 종속변수 y에 미치는 순수한 평균 변화량(편미분 관점)을 의미합니다.


로지스틱 회귀에서 입력 변수 $x$의 값이 크게 증가할 때 예측 확률 $p(X)$의 변화 양상에 대한 설명 중 올바른 것은 무엇인가?
로짓(Log-odds)은 선형적으로 증가하지만, 확률 $p(X)$는 시그모이드 함수를 통과하면서 비선형적으로 변화한다.(내 답변)
정답
로지스틱 회귀는 선형 결합식 z=β0+β1 x에 시그모이드 $\sigma(z)$를 씌우므로, 로짓(로그 오즈)은 선형 변함에 반해 실제 확률은 비선형 S자 곡선을 따라 변화합니다.



선형회귀와 달리 로지스틱 회귀에서 가중치(파라미터)를 추정할 때 닫힌 형태 해(Closed-form solution) 대신 경사하강법과 같은 수치적 최적화를 사용하는 이유는 무엇인가?
B. 로그 우도(Log-likelihood) 함수를 미분하여 0이 되는 지점을 나타내는 방정식의 해석적(Analytical) 해가 존재하지 않기 때문이다.(내 답변)
정답
로지스틱 회귀의 우도 함수 방정식은 비선형적이어서 a=b 형태로 풀어낼 수 있는 닫힌해(Closed-form solution)가 존재하지 않아 경사하강법 등 수치적 기법으로 최적 파라미터를 찾습니다.



LSTM의 셀 스테이트(Cell State, $C_t$)와 포겟 게이트(Forget Gate) 수식 $f_t = \sigma(W_f \cdot [h_{t-1}, x_t] + b_f)$에 대한 설명으로 옳은 것은?
포겟 게이트 계산 시 이전 히든 스테이트($h_{t-1}$)와 현재 입력($x_t$)을 연결(concatenate)하여 사용한다.
포겟 게이트 출력 $f_t$는 시그모이드 함수를 통과하여 0~1 사이 값을 가집니다. $f_t$가 **0에 가까울수록 이전 정보를 버리고(잊고)**, **1에 가까울수록 이전 정보를 거의 그대로 유지**합니다



트랜스포머 레이어를 쌓았을 때 나타나는 어텐션 패턴의 변화에 대한 설명으로 틀린 것은?
4번이 정답(틀린 설명)인 이유: 트랜스포머는 고정된 패턴을 유지하는 것이 아니라, 어텐션을 통해 그때그때 필요한 최적의 아키텍처(CNN, RNN, MLP 형태 등)를 동적으로 학습합니다.



CLIP의 멀티모달 정합(Alignment)을 최적화 목적함수로 직접 사용하는 응용 기법(Text-to-3D 등)
CLIP의 이미지 및 텍스트 인코더 자체는 고정(Freeze)한 상태로 활용
텍스트 설명과 생성 중인 이미지/3D 표현 사이의 유사도를 손실함수(Loss)로 사용
CLIP을 평가자(감정사) 역할로 두어 점수가 높아지도록 생성 대상의 파라미터를 고쳐나가는 방식
역전파 진행 시 CLIP 모델의 가중치는 고정(Freeze)되어 있으며, 역전파 기울기는 생성 대상인 이미지/3D 표현 파라미터를 업데이트하는 데만 사용
