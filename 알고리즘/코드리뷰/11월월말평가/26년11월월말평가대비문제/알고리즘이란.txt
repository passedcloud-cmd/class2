알고리즘이란?
- 유한한 단계를 통해 문제를 해결하기 위한 절차나 방법
- 어떤 일을 수행하기 위한 단계. 어떤 문제를 해결하기 위한 절차

알고리즘의 효율
- 공간적 효율: 필요로 하는 메모리 공간
- 시간적 효율: 작업을 완료하는 데 걸리는 시간. 입력 크기 n에 대한 연산 횟수로 나타내는 게 주.
- 효율성을 뒤집으면 복잡도. 복잡도가 높을수록 효율성은 저하

복잡도의 점근적 표기
- 시간이나 공간 복잡도는 입력 크기에 대한 함수로 표기
- (Big-Oh) O 표기법이 많이 사용 

자주 사용하는 O-표기
O(1) 상수 시간
O(logn) 로그(대수) 시간
O(n) 선형 시간
O(nlogn) 로그 선형 시간
O(n^2) 제곱 시간
O(n^3) 세제곱 시간


Q. 1부터 100까지의 합을 구하는 두 가지 알고리즘의 연산복잡도 설명
방법 1. 하나씩 더하기
  n = 100일 때 연산 : 덧셉 99번
  n = 1,000,000일 때 연산 : 덧셈 999,999번
    -> n에 비례해서 연산 횟수가 늘어남
    -> 복잡도: O(n)

방법 2. 공식 n(n+1)/2 사용
  연산: 덧셈 1번 + 곱셈 1번 + 나눗셈 1번 = 3번
    -> n과 상관 없이 연산 횟수는 3번
    -> 복잡도: O(1)
