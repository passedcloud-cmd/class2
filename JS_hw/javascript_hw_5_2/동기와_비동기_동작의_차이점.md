## 1. 개념

### 동기 (Synchronous)

코드가 작성된 순서대로 한 줄씩 실행된다.

앞의 작업이 끝나야 다음 작업이 시작된다.

오래 걸리는 작업이 있으면 그동안 다음 코드가 실행되지 못하고 멈춰 있다. → 블로킹(Blocking)

### 비동기 (Asynchronous)

시간이 걸리는 작업을 시작만 해 두고, 끝날 때까지 기다리지 않고 다음 코드를 먼저 실행한다. →  논블로킹(Non-blocking)

작업이 끝나면 미리 등록해 둔 콜백 함수가 나중에 실행된다.

## 2. 차이점

### 2-1. 실행 순서

| 구분 | 설명 |
| --- | --- |
| 동기 | 작성한 순서 = 실행 순서 |
| 비동기 | 작성한 순서와 실행 순서가 다를 수 있음. 시간이 걸리는 작업의 결과(콜백)는 나중에 실행됨 |

### 2-2. 대기 여부

| 구분 | 설명 |
| --- | --- |
| 동기 | 앞 작업이 끝날 때까지 기다림 (블로킹) |
| 비동기 | 기다리지 않고 다음 코드를 먼저 실행 (논블로킹) |

### 2-3. 사용하는 상황

| 구분 | 사용 상황 |
| --- | --- |
| 동기 | 변수 선언, 계산, 조건문/반복문 등 바로 끝나는 작업, 순서가 반드시 지켜져야 하는 간단한 로직 |
| 비동기 | 시간이 얼마나 걸릴지 모르는 작업 — 타이머(setTimeout), 서버 통신(axios, fetch), 파일 읽기 등 |

### 한눈에 비교

| 비교 항목 | 동기 | 비동기 |
| --- | --- | --- |
| 실행 순서 | 위에서 아래로 차례대로 | 오래 걸리는 작업의 결과는 나중에 |
| 대기 여부 | 기다림 (블로킹) | 기다리지 않음 (논블로킹) |
| 결과 처리 | 바로 다음 줄에서 사용 | 콜백 / .then() 안에서 사용 |
| 대표 예시 | console.log, 계산 | setTimeout, axios.get() |
